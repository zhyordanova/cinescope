# Project Requirements

## The Problem

Create a Netflix-style mobile home page using React Native, with movie data fetched from a public API.

You should:

- Build a home screen that shows lists of movies in both vertical and horizontal scrolling layouts.
- Add navigation to a Movie Details screen for any selected movie.

Use the following movie data API:

https://www.omdbapi.com/

You'll need to register for a free API key to fetch data.

## Requirements

The app must:

- Display a stylized homepage with scrollable vertical and horizontal lists (e.g., categories or trending movies).
- Navigate to a movie details screen upon selecting a movie item.
- Fetch and display real data using the OMDb API.
- Be structured and modularized in a way that could easily support additional screens and features in the future.

## Notes

- You can design the UI freely — it doesn't need to match Netflix exactly, but it should be visually clean and intentional.
- You can use navigation libraries such as React Navigation.
- We expect you to use functional components and Hooks.
- Strong organization and scalable architecture are key — imagine this as the foundation of a full-featured app.
- Use TypeScript.
- Feel free to use mockups or placeholders where API data is limited.
